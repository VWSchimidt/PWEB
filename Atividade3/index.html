1. Introdução

O crescimento do acesso à internet por celulares e tablets mudou a forma como os sites precisam ser feitos. Até o início dos anos 2010 a maior parte dos acessos vinha de computadores, mas hoje a maioria vem de dispositivos móveis.

É nesse contexto que surge o Design Responsivo: uma forma de construir sites que se adaptam automaticamente a qualquer tamanho de tela, sem precisar criar uma versão separada para celular e outra para computador. O termo foi criado por Ethan Marcotte em 2010, unindo três técnicas: grids fluidos, imagens flexíveis e media queries.

2.1 Conceito de Design Responsivo

Design Responsivo é a ideia de adaptar a página ao dispositivo que está acessando ela, considerando a largura da tela, a resolução e a orientação (retrato ou paisagem). Antigamente eram feitas duas versões de um mesmo site (uma para computador e outra para celular). Hoje, com o design responsivo, existe apenas um HTML e um CSS, e é o próprio CSS que reorganiza o layout.

Isso evita problemas comuns em telas pequenas, como precisar dar zoom ou rolar a página para os lados, e facilita a manutenção do site, já que qualquer alteração aparece em todos os dispositivos ao mesmo tempo.

2.4 Grids fluidos, media queries e imagens flexíveis

Três técnicas sustentam o design responsivo:

  • Grids fluidos: usar porcentagem em vez de pixel fixo, para os elementos crescerem ou diminuírem junto com a tela.
  • Media queries: regras de CSS que só valem a partir de uma certa largura de tela, usando @media.
  • Imagens flexíveis: usar max-width: 100% nas imagens para elas não ficarem maiores que o espaço disponível.

2.5 CSS Flexbox

O Flexbox organiza os elementos em uma linha ou em uma coluna, e ajuda a alinhar e distribuir o espaço entre eles. É muito usado em menus, listas de cartões e barras de navegação.

O elemento pai recebe display: flex e vira o "flex container". Os filhos diretos dele viram "flex items" e se ajustam automaticamente. As propriedades mais usadas são flex-direction, justify-content, align-items e flex-wrap.

2.6 CSS Grid

O CSS Grid organiza os elementos em linhas e colunas ao mesmo tempo, o que ajuda bastante para montar o esqueleto de uma página inteira (cabeçalho, menu, conteúdo e rodapé).

O elemento pai recebe display: grid e a propriedade grid-template-columns define quantas colunas existem. Um exemplo comum é repeat(3, 1fr), que cria três colunas do mesmo tamanho.

2.7 Flexbox ou Grid?

Flexbox e Grid não são concorrentes, e sim complementares. Uma boa regra é usar o Grid para organizar a estrutura geral da página, e o Flexbox para organizar os elementos menores dentro de cada parte da página, como os itens de um menu.

2.8 Imagens responsivas em HTML

Além do CSS, o próprio HTML tem recursos para imagens responsivas. O atributo srcset permite indicar várias versões da mesma imagem em tamanhos diferentes, e o navegador escolhe sozinho qual baixar. Já a tag <picture> permite mostrar imagens diferentes dependendo do tamanho da tela.

2.9 Breakpoints e Mobile-First

Um breakpoint é a largura de tela em que o layout muda. Um conjunto bem conhecido de breakpoints, popularizado pelo Bootstrap, é:

Largura Dispositivo
a partir de 576px Celular em modo paisagem
a partir de 768px Tablet
a partir de 992px Notebook
a partir de 1200px Desktop grande

A abordagem mobile-first significa escrever primeiro o CSS pensando no celular, e depois usar @media (min-width: ...) para acrescentar estilos quando a tela for maior. É assim que o CSS desta página foi organizado.

2.13 Boas práticas

  • Usar porcentagem, em ou rem em vez de pixel fixo sempre que possível
  • Deixar os botões grandes o suficiente para tocar com o dedo
  • Testar o site em telas de tamanhos diferentes
  • Mostrar primeiro o conteúdo mais importante em telas pequenas

3. Conclusão

O Design Responsivo é uma forma de pensar o desenvolvimento web que coloca a experiência do usuário em primeiro lugar, adaptando o site a qualquer tela. Ele depende do HTML semântico, do CSS (com Flexbox e Grid) e de imagens que se ajustam ao dispositivo. Aprender esses fundamentos é essencial para qualquer pessoa que trabalhe com desenvolvimento web hoje em dia.
